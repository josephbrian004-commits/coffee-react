# Brewed Culture

A premium coffee shop landing page built with React and Vite.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Production build

```bash
npm run build
```

## Repository status

This project is set up for a polished café-style landing page with:
- hero section
- menu cards
- about/story section
- reviews
- visit CTA
- responsive design

## Notes

This app is intentionally designed to be easy to extend into a fuller coffee shop experience with a cart, checkout flow, or multi-page navigation.
